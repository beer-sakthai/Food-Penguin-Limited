# Food Penguin Limited — Deployment notes

## Build
```bash
npm install
npm run build
npm run lint
```

## Deploy to Vercel

### Option A: manual (recommended first time)
```bash
npx vercel login
npx vercel --prod
```

### Option B: using a token
```bash
npx vercel --token=<YOUR_TOKEN> --prod
```

## Environment variables to set in Vercel dashboard
- `GEMINI_API_KEY` (optional, falls back to simulation mode)
- Any Firestore / database connection strings

## Files
- `vercel.json` — routes API + static build output.
- `dist/` — generated by `npm run build`.
- `server.ts` — Express API backend.

## Watchdog
A daily cron job runs `npm run lint` + `npm run build` at 08:00 and reports failures.
