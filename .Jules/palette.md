## 2025-05-22 - [Success Feedback for Form Submissions]
**Learning:** In dashboards where actions (like committing logs) don't trigger a page reload, users often lack immediate visual confirmation that their data was saved. Adding a temporary "Success" state to the submit button (color change + icon change + text update) provides instant, clear feedback without disrupting the flow.
**Action:** Always implement a 1-3 second success state for primary action buttons that perform background updates.
